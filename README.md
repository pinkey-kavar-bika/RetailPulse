# RetailPulse: AI-Powered Customer Analytics & Demand Forecasting

This project analyzes the Online Retail II dataset to generate business insights through customer segmentation, demand forecasting, churn prediction, and inventory optimization.

## Dataset
- Online Retail II (UCI Machine Learning Repository)
- Time Period: December 2009 – December 2011

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Prophet
- Streamlit
- Git & GitHub
